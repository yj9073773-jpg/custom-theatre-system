# Custom Theatre System

**Foundry VTT V13용 비주얼 노벨풍 스탠딩 모듈입니다.**

AI를 활용한 바이브 코딩으로 제작되었으며, D&D 5e와 Call of Cthulhu 7th Edition 환경에서 정상 구동을 확인했습니다.

다른 게임 시스템에서도 사용은 가능하지만, 시스템별 주사위 결과 출력 방식에 따라 일부 기능에 수정이 필요할 수 있습니다. 또한 제작자의 플레이 환경을 기준으로 테스트되었기 때문에, 다른 모듈과의 호환성은 충분히 검증되지 않았습니다.

채팅 초상화에 영향을 주거나 채팅 메시지를 병합하는 모듈과 함께 사용할 경우 충돌이 발생할 수 있습니다. 해당 기능을 사용하는 모듈이 있다면 관련 설정을 확인해 주세요.

**이 모듈은 `custom-chat-channels`를 종속 모듈로 사용합니다.** https://github.com/yj9073773-jpg/custom-chat-channels

`custom-chat-channels`는 채팅 탭 분리와 스탠딩 전용 채널의 추가 및 관리를 담당합니다. 현재 버전에서는 `custom-chat-channels`와 함께 사용하는 것을 권장합니다.

## 기능 소개

비주얼 노벨풍의 스탠딩 연출을 구현하는 모듈입니다.

최대 4명의 캐릭터를 동시에 무대에 배치할 수 있으며, 등록한 스탠딩 이미지는 무대뿐만 아니라 채팅 초상화에도 적용할 수 있습니다.

채팅 초상화를 사용하려면 먼저 액터별 초상화 영역을 지정해야 합니다.

### 액터의 표정

표정 추가 기능을 통해 캐릭터의 표정 이미지를 등록하고 관리할 수 있습니다.

- 표정 이미지 추가 및 삭제
- 이름 색상 지정
- 액터별 스탠딩 크기 조절

등록한 표정은 @표정 커맨드를 통해 채팅에서 사용할 수 있습니다.

표정 커맨드 사용 시 다른 텍스트를 함께 입력하면 커맨드 외의 텍스트는 처리되지 않습니다. 표정을 커맨드로 변경할 때는 @표정 커맨드만 입력해 주세요.

### 초상화 영역 지정

등록한 스탠딩 이미지 중 하나를 기준으로 채팅 초상화 영역을 지정할 수 있습니다.

컬러 피커를 이용해 초상화 영역의 배경색을 지정하거나 투명하게 설정할 수 있습니다.

**프리셋 기능**

기본 영역 외에 2개의 추가 프리셋을 제공합니다.

특수한 형태의 스탠딩을 사용하여 기본 초상화 영역이 얼굴을 벗어나는 경우, 프리셋을 이용해 다른 영역을 지정할 수 있습니다.

체크박스를 통해 각 프리셋에 적용할 표정을 선택할 수 있습니다.

<img width="408" height="372" alt="초상화 영역 지정" src="https://github.com/user-attachments/assets/b1641914-292b-4e36-bc48-5a6d66a28eee" />

### 미사용 표정 파일 찾기

표정을 삭제하면 모듈의 표정 목록에서는 제거되지만, 업로드된 이미지 파일은 자동으로 삭제되지 않고 저장 폴더에 남아있습니다.

**미사용 표정 파일 찾기** 기능을 이용하면 현재 액터와 연결되지 않은 이미지 파일을 찾아 목록으로 확인할 수 있습니다.

필요한 파일을 확인한 후 직접 삭제할 수 있습니다.

<img width="238" height="368" alt="미사용 표정 파일 찾기" src="https://github.com/user-attachments/assets/cca7cbbf-7923-4c16-a06c-511f6fba5fd7" />

### 표정 선택 도우미

무대 매니저 아이콘(가면 모양)을 오른쪽 클릭하면 표정 선택 도우미가 열립니다.

등록된 표정 목록을 확인하고 원하는 표정을 클릭하여 현재 스탠딩에 바로 적용할 수 있습니다.

### 기타 기능

- 채팅 병합
- 채팅 초상화 크기
- 채팅 초상화 라운드니스
