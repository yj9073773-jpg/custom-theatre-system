## 기능 소개

비주얼 노벨풍의 스탠딩 연출을 구현하는 모듈입니다.  
최대 4명의 캐릭터를 동시에 무대에 배치할 수 있으며, 등록한 스탠딩 이미지는 무대뿐만 아니라 채팅 초상화에도 적용할 수 있습니다.

채팅 초상화를 사용하려면 먼저 액터별 초상화 영역을 지정해야 합니다.

### 액터의 표정

표정 추가 기능을 통해 캐릭터의 표정 이미지를 등록하고 관리할 수 있습니다.

- 표정 이미지 추가 및 삭제
- 이름 색상 지정
- 액터별 스탠딩 크기 조절

### 초상화 영역 지정

등록한 스탠딩 이미지 중 하나를 기준으로 채팅 초상화 영역을 지정할 수 있습니다.

컬러 피커를 이용해 초상화 영역의 배경색을 지정하거나 투명하게 설정할 수 있습니다.

**프리셋 기능**

기본 영역 외에 2개의 추가 프리셋을 제공합니다. 특수한 형태의 스탠딩을 사용하여 기본 초상화 영역이 얼굴을 벗어나는 경우, 프리셋을 이용해 다른 영역을 지정할 수 있습니다.

체크박스를 통해 각 프리셋에 적용할 표정을 선택할 수 있습니다.

### 미사용 표정 파일 찾기

표정을 삭제하면 모듈의 표정 목록에서는 제거되지만, 업로드된 이미지 파일은 자동으로 삭제되지 않고 저장 폴더에 남아있습니다.

**미사용 표정 파일 찾기** 기능을 이용하면 현재 액터와 연결되지 않은 이미지 파일을 찾아 목록으로 확인할 수 있습니다. 필요한 파일을 확인한 후 직접 삭제할 수 있습니다.

### 표정 선택 도우미

무대 매니저 아이콘(가면 모양)을 오른쪽 클릭하면 표정 선택 도우미가 열립니다.

등록된 표정 목록을 확인하고 원하는 표정을 클릭하여 현재 스탠딩에 바로 적용할 수 있습니다.
